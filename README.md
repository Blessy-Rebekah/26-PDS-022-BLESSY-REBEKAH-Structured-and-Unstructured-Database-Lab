# Overall Observations

1. Core SQL operations—such as CRUD actions, string manipulation, and conditional `CASE` logic—form the essential base for manipulating, cleaning, and transforming relational data structures.
2. Advanced relational querying techniques like Subqueries, Joins, Aggregations with `GROUP BY`, and Window Functions enable complex multi-table analysis, running calculations, and contextual ranking without mutating source tables.
3. Database extensibility and pattern matching through User-Defined Functions (UDFs) and Regular Expressions allow custom business logic implementation and flexible pattern extraction directly within database engines.
4. Non-relational (Document/NoSQL) operations using MongoDB demonstrate document-based CRUD, schema flexibility, dynamic array manipulations, and pipeline aggregations—including relational-style joins via `$lookup`.
5. Performance engineering and database administration fundamentals—including B-tree/field indexing, import/export pipelines, automated backup/restore routines, and replica sets—ensure query optimization, system availability, and data fault tolerance across both SQL and NoSQL engines.
